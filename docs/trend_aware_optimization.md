## 一、趋势感知权重优化功能

### 1.1 功能概述

基于时间序列分析各维度预测能力的变化趋势，自动调整评分权重：
- **趋势检测**：使用线性回归拟合 IC 值变化趋势
- **趋势加权**：对改善的维度增加权重，对下降的维度减少权重
- **新闻热点结合**：支持根据新闻情绪因子调整权重

### 1.2 核心算法

**趋势检测指标**：
- 斜率 (Slope)：IC 值随时间的变化率
- R 平方 (R²)：趋势拟合度
- 趋势强度 = 斜率 × R²

**趋势分类**：
- ↑ 改善：斜率 > 0.001
- → 稳定：|斜率| ≤ 0.001
- ↓ 下降：斜率 < -0.001

**权重计算公式**：
```
综合得分 = |当前 IC| + 趋势强度 × trend_weight + 趋势方向加分
趋势方向加分：改善 +0.05, 下降 -0.05
```


### 2.3 UI 界面功能

1. **板块热度排行榜**：卡片式布局显示 Top 15 热门板块
2. **板块热度详情表**：显示热度分数、关键词数量、热度等级
3. **板块相关股票查询**：点击板块查看相关股票列表
4. **实时热词监控**：显示最近 N 天的热词 Top 30

### 2.4 使用方法

1. 启动 Streamlit 应用：
   ```bash
   streamlit run ui/app.py
   ```

2. 选择"热点看板"页面

3. 调整查看天数（1-7 天）

4. 查看热门板块排行和相关股票

## 六、注意事项

1. **Streamlit 缓存问题**：
   - 如果遇到 `AttributeError: 'StockScorer' object has no attribute 'get_recommendations_from_db'` 错误
   - 解决方法：停止 Streamlit 进程（Ctrl+C），重新启动
   - 或清除缓存：
     ```bash
     Get-ChildItem -Recurse -Directory -Filter __pycache__ | Remove-Item -Recurse -Force
     Get-ChildItem -Recurse -Filter *.pyc | Remove-Item -Force
     ```

2. **趋势感知优化需要足够的历史数据**：
   - 建议至少有 30 个交易日的推荐数据
   - 数据量不足时会自动使用默认权重

3. **板块相关股票匹配**：
   - 当前通过股票名称关键词匹配
   - 可能需要更精确的行业分类数据来提高匹配准确度
