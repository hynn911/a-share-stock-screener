### 3. 持仓管理当前价格不是实时价格

**修复内容**：修改 `core/position.py` 的 `get_latest_close_price()` 方法，优先获取实时价格

**修改前**：
- 仅从数据库获取历史收盘价
- 无法反映盘中实时价格变化

**修改后**：
- 优先从 AkShare API 获取实时价格
- 休市期间或 API 失败时自动回退到数据库收盘价
- 支持 `use_realtime` 参数控制是否启用实时价格

**代码变更**：
```python
def get_latest_close_price(self, stock_code: str, use_realtime: bool = True) -> float:
    """获取最新价格（优先实时，休市时使用本地存储）"""
    if use_realtime:
        # 1. 优先尝试从 API 获取实时价格
        try:
            df = ak.stock_zh_a_spot_em()
            stock_data = df[df['代码'] == stock_code]
            if not stock_data.empty and pd.notna(stock_data.iloc[0]['最新价']):
                real_price = float(stock_data.iloc[0]['最新价'])
                if real_price > 0:
                    return real_price
        except Exception:
            pass  # API 失败，回退到本地数据

    # 2. 从数据库获取最新收盘价（盘后数据或休市时使用）
    try:
        latest = self.db.query(StockDaily).filter(
            StockDaily.stock_code == stock_code
        ).order_by(desc(StockDaily.trade_date)).first()
        if latest:
            return latest.close
        return None
    except Exception:
        return None
```

## 注意事项

1. **Streamlit 缓存**：修改代码后必须重启 Streamlit 才能加载新模块
2. **实时价格**：交易时间内才能获取实时价格，休市期间显示最新收盘价
3. **数据完整性**：确保数据库中有足够的历史推荐数据（建议至少 30 个交易日）
4. **代码改动后缓存清理规程**（重要！）：
   ```bash
   # 每次修改代码后必须执行以下步骤确保新代码生效

   # 1. 清理 Python 缓存
   cd stock
   find . -type d -name '__pycache__' -exec rm -rf {} + 2>/dev/null
   find . -name '*.pyc' -delete

   # 2. 清理 Streamlit 缓存
   rm -rf ~/.streamlit/*.proto 2>/dev/null

   # 3. 重启 Streamlit
   # 按 Ctrl+C 停止当前进程，然后重新运行：
   streamlit run ui/app.py

   # 或者使用一键清理重启脚本（推荐）
   bash scripts/clean_and_restart.sh
   ```

5. **验证代码生效方法**：
   - 在修改文件后添加明显的日志输出或打印语句
   - 重启 Streamlit 后检查日志是否显示新内容
   - 测试修改的功能是否按预期工作
   - 如果仍然报错，确认缓存是否彻底清理
